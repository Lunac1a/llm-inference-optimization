# 最终 mixed 实现扩大评测：冻结协议

2026-09-19，GPU 执行前制定。用户明确停止进一步优化，要求整理仓库后进行 benchmark，并授权最多三小时 GPU 生命周期（含启动和集成验证）。默认服务为 mixed。

## 固定实现与数据

Qwen3-4B revision `1cfa9a7208912126459214e8b04321603b3df60c`，BF16 权重，vLLM 0.23.0。三组：BF16 Flash、原生 per-token-head FP8 Triton、0.1.3 最终 mixed Triton。mixed 采用已经验收的 BLOCK_M=64 + 单循环整块来源分支，不新增调参。

三组均为 16640 上下文、2048 分块、8 sequence slots、4 GiB KV 字节预算、NHD、eager、开启 prefix caching。单并发，每次测量前清空前缀缓存，检查零命中和零抢占。保留实际缓存 token 容量，不把容量等同吞吐或上下文上限。

官方 NVIDIA/RULER v1 commit `c3f5e3b4f87f97e048793bb510a3a6b19a46bf3a`，13 任务 × 4K/8K/16K × 20 新样本 × 3 实现 = **2340 正式响应**。原封不动使用官方生成器、模板、语料及评分；数据 seed=20260919，QA 使用官方 `pre_samples=100` 选未评测问题序号。生成后检查新旧 token-ID 哈希与 QA 问题不重合；不按答案或模型分数挑题，重合或生成故障时停止而非替换样本。不同长度可使用相同 QA 问题，置信区间保留跨长度配对结构。

非思考 Qwen 聊天模板 + 官方 assistant prefix，经固定 prompt IDs 送 `/v1/completions`，greedy、seed42、正常 EOS、官方输出上限。旧评测及调参见过的样本不纳入本轮质量总分。

## 执行与时间

先完成源码/安装包 CPU 回归、包内容检查；冻结所有服务源码、工具、协议、环境、生成数据、上游生成/评分源码与语料哈希。GPU 先验证集成后的 20 个固定数值用例，对 FP32 混合精度参考 max_abs ≤0.02、RMS ≤0.002，对旧实现 max_abs ≤0.002、RMS ≤0.0002，并验证输入不被修改与关闭分支输出一致。没有性能调参或重新选择 tile。

GPU 总进程生命周期最多 **10800 秒**；数值检查最多 300 秒。每请求最多 120 秒。主机可用内存低于 2 GiB、相对阶段开始 swap 增加超过 256 MiB、OOM、非空要求失败、路由错误、缓存命中/抢占、源码变化或预算到期均停止。原始日志和已完成响应保留，不自动重跑，不缩题，不据质量调整阈值。清理仅限本任务拥有的进程。

将每长度 20 题分为序号0–9和10–19两块，每块每任务10题；三组在每块使用相同样本。顺序：

| 长度 | 第一块 | 第二块 |
|---|---|---|
| 4K | BF16 / FP8 / mixed | mixed / FP8 / BF16 |
| 8K | FP8 / mixed / BF16 | BF16 / mixed / FP8 |
| 16K | mixed / BF16 / FP8 | FP8 / BF16 / mixed |

每块每组新服务，启动后一次短热身。第一块三组完成后继续第二块。每次服务启动，在质量请求之前，额外以旧 `niah_single_1` 序号0的该长度输入做一次热身和三次测量，强制输出32 tokens、忽略 EOS、每次清空 prefix。共 **54 次普通延迟测量**、18次长输入热身、18次短热身。固定输出延迟不参与 RULER 质量分数。该设计交错组别但不消除设备温度/频率漂移，也不是生产并发或 p95 测试。

## 结果口径

报告官方 task macro 分数、逐任务分数、完全答对、空输出、截断、逐题变化；重点展示 CWE，但不排除其他任务。每长度按任务分层，10000次配对 bootstrap 给出 mixed-minus-BF16 与 mixed-minus-FP8 的95%区间；跨长度按相同任务/样本序号联合重采样。

质量差同时报告百分点和相对百分比，明确对照。小样本区间不证明普遍无损，不设结果必须好看的推广门槛。若实际损失扩大，照实报告。

正常 EOS 请求的总耗时、TTFT、E2E、输出 token、缓存容量单独列出；答案长短不同，所以不将其称为等输出吞吐加速。固定32 token组报告两块和合并的首非空 SSE 内容时间、E2E；不称为设备端精确 token 延迟。没有新的 kernel 微基准或 profiler 调优。
