## 1. 数值与隔离 kernel 测量

- 同时比较原始源码、改造后关闭开关、开启分段读取三条路径。关闭开关必须逐元素等于原始源码；候选对原始输出 max_abs ≤ 0.002、RMS ≤ 0.0002。
- 独立 FP32 数学参考：从实际 FP8 页和 per-token-head scales 恢复历史，与当前 BF16 拼接后做 causal attention；两者对参考均需 finite、max_abs ≤ 0.02、RMS ≤ 0.002。缓存字节与当前 BF16 张量在调用前后不变。
- seeds=42/43；固定 `(history,current,heads,kvheads,dim)`：`(0,17,8,8,64)`、`(1,2,32,8,128)`、`(7,1,32,8,128)`、`(31,19,32,8,128)`、`(32,33,32,8,128)`、`(33,32,16,4,64)`、`(2049,37,32,8,128)`、`(4093,129,32,8,128)`、`(4096,2048,32,8,128)`、`(12289,129,32,8,128)`。共 20 例，反序物理页、非连续 V，覆盖零历史、decode-sized 输入、对齐与跨界、query 尾部。生产 Decode 仍走上游。
- 三个固定性能形状：history=2048/8192/14336，current=2048，32 query heads / 8 KV heads / head_dim128，seed42。原始/候选各热身 5 次，再做 20 对交替 AB/BA 的 CUDA event 测量，每次计时连续 5 次 kernel 调用。记录原始样本、寄存器/共享内存/spills。
- micro 进入服务测量门槛：三个形状中位数比值的几何均值 ≤ 0.97，任一比值 ≤ 1.03。未通过只报告本候选无足够收益，不追加参数搜索。
