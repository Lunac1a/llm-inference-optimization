# RULER v1：mixed KV 质量与效率评测协议

2026-09-16。目的：测量 BF16 baseline、原生 FP8 KV 和 mixed KV 在公开长上下文任务上的质量/效率取舍。本轮不优化 kernel，不根据结果改默认配置。

## 固定基准与对照

- 官方 NVIDIA/RULER v1，源码固定 `c3f5e3b4f87f97e048793bb510a3a6b19a46bf3a`，原始 13 个任务与官方评分函数。使用同一份冻结题目与答案。
- 长度档 4096、8192、16384，官方长度包括回答预留；实际 tokenizer token 数单独保存并检查不超出 16640 窗口。不截断题目。
- 本地固定 Qwen3-4B revision `1cfa9a7208912126459214e8b04321603b3df60c`，BF16 权重，vLLM 0.23.0，RTX 4090 Laptop。
- 四组：BF16/FlashAttention baseline、BF16/Triton 后端对照、原生 per-token-head FP8/Triton、当前 mixed/Triton。
- 全部使用 16640 最大上下文、2048 分块、8 sequence slots、4 GiB KV 字节预算、eager、前缀缓存开启。此为匹配资源的实验配置，不修改产品默认 baseline。等字节下 BF16/FP8 token 容量不同，分别记录。
- 质量请求单并发；每题前清空前缀缓存，所有题均实际执行 Prefill。原始指标和路由日志验证缓存状态/实现。性能结论仅适用于此冷输入、单请求负载。
- 使用模型的非思考聊天模板及官方 assistant answer prefix，将固定 prompt token IDs 送到 `/v1/completions`。不用产品文档提示、不增加答案约束。temperature=0、seed=42、正常 EOS、官方任务输出上限。长度截断与空输出单独报告。

## 样本与时间规则（GPU 前冻结）

每任务/长度预生成 11 题；序号 10 用于预检，其余 0–9 为正式候选。预检在 8K 的全部 13 任务、全部 4 组运行，每组额外 1 个短热身，共 56 请求，不纳入正式分数。

整个阶段最多 7200 秒 GPU 进程生命周期，含启动/预检/正式/退出。预检上限 1200 秒。每请求上限 120 秒。单组故障、OOM、服务异常、主机可用内存低于 2 GiB、swap 增长超过 256 MiB 或时间超限即停止，保留所有失败，不自动重跑。

正式题量仅由预检时间决定，不查看预检正确率选择题量：每任务取四组最大请求时长并求和为 t，s 为最大启动时长。预测成本 `12*s + 4*n*(0.7+1+2)*1.25*t`，长度因子覆盖 4K/8K/16K，另留 25% 抖动余量。选择 n=10 或 n=5 中，预测成本不超过剩余时间 80% 的最大者；两者均不满足则停止在预检，不擅自缩减任务。题量在正式请求前写入冻结清单。该公式在 GPU 预检前确定，不依赖已测延迟或正确率。

正式按长度分块：4K 顺序 baseline/Triton-BF16/FP8/mixed，8K 逆序，16K FP8/mixed/baseline/Triton-BF16。每组新建服务，每组 1 次短热身。每任务每长度固定 n 题，最多 1560 正式请求，另 12 次热身。不追加采样、不测后调参、不改门槛。

## 评分与解释

- 复用官方大小写不敏感字符串包含评分：多答案任务按命中比例给部分分，QA 按任一参考答案命中。先执行官方输出清理。
- 报告官方 task macro average、各任务/长度分数、逐题差异、完全答对到未完全答对的转变、反向改善、空输出与输出截断。
- 每长度按任务分层做 10000 次配对 bootstrap，报告 mixed-minus-BF16、mixed-minus-FP8 等差值的 95% 区间。跨长度均值保留同任务/序号关联。小样本不能证明普遍无损。
- 本轮主要估计分数差，不以通过无损门槛为目标。小样本 bootstrap 不包含未观察到的错误类型；即使逐题相同、区间为零，也不能据此宣称总体无损。
- 报告 TTFT、E2E、实际输出 token、输出 token/请求总耗时、首内容后观察生成速率、流式内容块间隔、KV token 容量。输出不同会影响耗时，真实任务性能不等于固定输出吞吐基准，不报生产 SLA。
- 分数差的主要科学对照是相同 Triton 后端；FlashAttention 比较代表默认路线到候选的整体变化。

本轮是公开 RULER 的小样本、4K/8K/16K 本地评测，不是完整 500 题/任务或 128K 榜单成绩；厂商报告只作参考。本轮数据、原始 SSE、启动配置、模型版本、指标、源码哈希和时间账本保存于 `.local/research/ruler-tradeoff-2026-09-16/`。
